Quadratic equations by factorisation

Lesson outline

Objectives

  • Factorise a quadratic of the form x² + bx + c.
  • Solve the equation by setting each factor to zero.
  • Check answers by substitution.

Plan

  1. Starter (5 min): Expand (x + 2)(x + 3) together. Ask what numbers multiply to 6 and add to 5.
  2. Teach (12 min): Factorise x² + 7x + 12 on the board. Show the sum-product table.
  3. Worked example (8 min): Solve x² − 5x + 6 = 0. Roots: x = 2, x = 3.
  4. Practice (10 min): Five questions in pairs, rising difficulty.
  5. Exit check (5 min): One question on paper. Collect and sort into got it / not yet.

Class notes

A quadratic equation has the form ax² + bx + c = 0. When a = 1, look for two numbers that multiply to c and add to b. Write the equation as (x + p)(x + q) = 0. If a product is zero, one of the factors must be zero, so x = −p or x = −q.

Common mistakes

  • Mixing up signs when c is negative.
  • Forgetting to set the equation to zero first.
